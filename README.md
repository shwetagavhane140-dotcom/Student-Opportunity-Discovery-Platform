# Student Opportunity Discovery Platform

A smart platform that helps students discover internships,
hackathons, scholarships, courses, certifications and other
opportunities from one place.

## 🚀 Live Demo

https://student-opportunity-discovery-platform.vercel.app

## 💡 Problem Statement

Students often struggle to find relevant opportunities because
information is scattered across different websites and platforms.

## ✨ Features

- 🔍 Search opportunities
- 🎯 Filter opportunities
- 💡 Smart opportunity recommendations
- 🔖 Bookmark opportunities
- 👤 Student profile
- 📊 Personalized dashboard
- 📄 Opportunity details
- 🔗 External application links

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Vercel

## 📂 Project Structure

- index.html – Home page
- opportunities.html – Opportunities listing
- details.html – Opportunity details
- dashboard.html – Student dashboard
- profile.html – Student profile
- how-it-works.html – How the platform works
- style.css – Styling
- script.js – JavaScript functionality

## ▶️ How to Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

## 🌐 Deployment

The project is deployed using Vercel.

Live Demo:
https://student-opportunity-discovery-platform.vercel.app
